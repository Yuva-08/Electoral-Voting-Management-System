# Electoral Voting Management System

## Project Description
The Electoral Voting Management System is a C programming-based application designed to manage a simple election process.

It allows voters to register, cast their votes, and view election results.

## Features
- Voter Registration
- Candidate Listing
- Secure One-Time Voting (within the running program)
- Vote Counting
- Election Result Display
- Winner Announcement

## Technologies Used
- Programming Language: C
- Online Compiler: OnlineGDB
- Data Structures: Structures, Arrays, Singly Linked List

## How to Run
1. Compile the voting_system.c file using a C compiler.
2. Run the executable.
3. Register voters.
4. Cast votes using voter IDs.
5. View election results.
